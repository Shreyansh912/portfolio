## 🚀 Featured Projects

* **Bird Detection System** — Computer vision pipeline for detecting birds from images and videos using Python, OpenCV, PyTorch, and YOLO.
* **AI PDF Assistant** — Document-based RAG application built with Python, LangChain/LLMs, and FastAPI.
* **Student Expense Tracker** — Full-stack web application designed for managing and analyzing daily student expenses.
* **CNN from Scratch (NumPy)** — Custom implementation of a feed-forward Convolutional Neural Network from first principles without deep learning libraries.
* **Shape Classification (PyTorch CNN)** — End-to-end binary image classification model utilizing 4 residual blocks, Batch Normalization, and Cosine Annealing learning rate scheduling.
